Renumbering plan for lecture code files
=======================================

Goal
----
Rename every lecture script that matches `ddd_*.py` so that:
- the descriptive suffix after the underscore is unchanged
- the existing order (sorted by current `ddd`) is preserved
- consecutive files differ by exactly 10 in their numeric prefix

Numbering rule
--------------
- Start at 010 for the first file in current order.
- Each next file gets previous + 10.
- Resulting prefixes are always multiples of 10: 010, 020, 030, ...
- Zero-pad to three digits (`ddd`), same pattern as today.

Why start at 010
----------------
Most of the course already uses the 010 / 020 / 030 style. Starting at 010 keeps
that convention and gives a clean gap of 10 between every consecutive file,
including the early consecutive block (005–009) and the tight inserts
(144/145, 221/231/241).

File count: 42
Final range: 010 … 420
  (010 + 10 * (42 - 1) = 420)

Safe rename procedure (when approved)
-------------------------------------
Many new names collide with existing names (e.g. current 100_... becomes 150_...,
while another file also targets an intermediate number). Direct in-place renames
would overwrite or fail.

Two-phase approach:
1. Rename every `ddd_name.py` -> `__tmp_##_name.py` using the new numbers.
2. Rename each temp file to its final `NEW_ddd_name.py`.

Prefer `git mv` so history is preserved.

Out of scope for this rename
----------------------------
- Do not change file contents in this step (slide titles, print strings, comments
  that mention old numbers stay as-is unless a follow-up pass is requested).
- Do not rename non-matching files (README, helpers, this plan file, etc.).
- Do not invent new descriptive suffixes.

Open choice (confirm before execute)
------------------------------------
Starting number is proposed as 010. Alternatives if preferred:
- Keep first file as 005, then 015, 025, ... (preserves current first number;
  prefixes are no longer multiples of 10).
- Start at 000 or 001 with gap 10.

Default for execution: start at 010, gap 10, as mapped above.
